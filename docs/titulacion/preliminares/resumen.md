# Resumen

El presente trabajo documenta el desarrollo e implementación de UCES Plataforma de Talento, una aplicación web de tipo MVP (*Minimum Viable Product*) orientada a digitalizar el proceso de reclutamiento y preselección de candidatos del área de Recursos Humanos de la Universidad Capital de Estudios Superiores (UCES), Zamora, Michoacán. La problemática de origen consistía en la ausencia de una etapa de evaluación estructurada previa a la entrevista presencial, lo que implicaba una carga administrativa elevada y una revisión de candidatos sin información estandarizada sobre sus competencias.

El objetivo general fue desarrollar una plataforma funcional que centralizara y digitalizara las actividades principales del proceso, incluyendo el registro de candidatos con protección criptográfica de la CURP, la aplicación de una evaluación psicométrica basada en el modelo de los Cinco Grandes factores de personalidad, la realización de evaluaciones de conocimientos con temporizador, la carga de evidencia práctica y la revisión administrativa de resultados. La metodología empleada fue el prototipado evolutivo, desarrollado en ocho iteraciones documentadas entre diciembre de 2025 y mayo de 2026, tomando como base de especificación el análisis y diseño previo elaborado por Arciniega Robles (2026) en el Trabajo A.

Las tecnologías principales utilizadas fueron Next.js 16.1.1 con App Router, TypeScript 5, React 19, Tailwind CSS, shadcn/ui, Supabase (PostgreSQL 16, Auth, Storage) y despliegue en Vercel. El modelo de datos relacional comprende 13 tablas con Row Level Security habilitado en todas ellas, y la API expone 13 Route Handlers protegidos mediante verificación de JWT y confirmación de rol en el servidor.

La validación funcional se realizó mediante 22 casos de prueba documentados: 16 casos aprobados (72.7 %), 2 aprobados parcialmente (9.1 %), 3 parciales por ausencia de endpoint REST en los componentes correspondientes (13.6 %) y 1 bloqueado por no ser reproducible en el entorno de prueba (4.5 %). Se identificaron cinco discrepancias entre el diseño del Trabajo A y la implementación resultante, todas caracterizadas y documentadas. Las principales limitaciones del MVP incluyen la ausencia de filtro automático por clasificación psicométrica, la inoperatividad del rol de revisor, la falta de notificaciones automáticas y la imposibilidad de verificar el comportamiento del sistema ante expiración de sesión prolongada.

El sistema cumple el objetivo general y cinco de los siete objetivos específicos de forma plena; los dos restantes se cumplen con matices documentados en las incidencias INC-6B-01 e INC-6B-02. Se concluye que el MVP constituye una base técnica sólida, funcional y extensible para la gestión digitalizada del proceso de reclutamiento de UCES.

**Palabras clave:** plataforma web, reclutamiento universitario, prototipado evolutivo, evaluación psicométrica, Supabase, Next.js, MVP.
